# TSP 四种启发式求解方法对比实验

蚁群算法（MMAS）、禁忌搜索、模拟退火、遗传算法求解对称旅行商问题（TSP），并以 **状态压缩动态规划（Held-Karp）** 的精确最优解作为对拍基准，量化每种启发式算法的绝对误差、相对误差与最优命中率。

- 语言 / 标准：**C++17**，无任何第三方依赖
- 实现形态：单文件 `src/tsp_experiment.cpp`（约 1 000 行），另附 Visual Studio 工程
- 完整实验报告见 [`docs/实验报告.md`](docs/实验报告.md)

---

## 1. 实验设计

| 项目 | 设置 |
| --- | --- |
| 规模 | n = 10 / 15 / 20（各 5 个随机实例）+ n = 30（3 个实例，扩展规模） |
| 重复轮数 | 每（实例 × 算法）30 轮，n=30 为 10 轮；单格样本量 150 / 30 |
| 数据生成 | `std::mt19937_64`，主种子 `20261124`，坐标取 [0,1000]² 上的整数点 |
| 精确基准 | Held-Karp 状压 DP，O(n²·2ⁿ)；n=10 另用全排列暴力枚举交叉验证 |
| 距离 | 欧氏距离（对称矩阵，等价于 TSPLIB 的 `EUC_2D`） |
| 计时 | `std::chrono::steady_clock`，仅统计算法调用本身 |

算法种子由 `(n, 实例号, 算法编号, 轮次)` 线性组合派生，因此**同一实例、同一算法、同一轮次在任何机器上都可逐位复现**；只有"耗时"一项随硬件与编译器变化。

## 3. 构建与运行

### 3.1 命令行（任意平台）

```bash
g++ -O2 -std=c++17 -o tsp_experiment src/tsp_experiment.cpp
./tsp_experiment        # 默认每个组合 30 轮
./tsp_experiment 10     # 可选参数：指定重复轮数
```

约 6 秒跑完，结果写入 `results/`（相对当前工作目录），并在控制台打印汇总表。
MSVC 亦可直接 `cl /O2 /std:c++17 /utf-8 src\tsp_experiment.cpp`。

### 3.2 Visual Studio

用 VS 打开 `旅行商问题的多种方式求解的对比.slnx`，选择 `x64` + `Release` 生成即可。
工程已为四个配置统一加了 `/utf-8`（源码含中文注释与输出），并以 `NOMINMAX` 规避了
`<windows.h>` 的 `min` / `max` 宏与 `std::min` / `std::max` 的冲突。

## 4. 参数配置

| 算法 | 关键参数 | 取值 |
| --- | --- | --- |
| ACO（MMAS） | 蚂蚁数 / 迭代 / α / β / ρ | 15 / 150 / 1.0 / 4.0 / 0.15，信息素钳制在 [τmin, τmax] |
| 禁忌搜索 | 迭代 / 邻域 / 禁忌长度 / 停滞阈值 | 2000 / 全 2-opt 邻域 best-improvement / 7+⌊n/4⌋+U{0..4} / 50 |
| 模拟退火 | 迭代 / 初温 / 终温 / 降温 | 10⁵ / 由 80% 接受率反解 / 0.01 / 几何降温 |
| 遗传算法 | 种群 / 代数 / p_c / p_m / 精英 | 80 / 150 / 0.9 / 0.25 / 2，OX 交叉 + 逆转变异 |

四种算法的参数按"单轮墙钟耗时处于同一量级（n=20/30 时 1~5 ms）"整定，使比较落在同一计算预算附近。

## 5. 主要结果

平均相对误差（相对精确最优解 / best-known）与最优命中率，括号内为平均单轮耗时：

| n | ACO | Tabu | SA | GA |
| --- | --- | --- | --- | --- |
| 10 | 0%（100%，0.39 ms） | 0%（100%，0.60 ms） | 0%（100%，2.56 ms） | 0%（100%，1.63 ms） |
| 15 | 0.255%（81.3%，1.04 ms） | **0%（100%，0.81 ms）** | 0.014%（98.0%，2.57 ms） | 0.814%（75.3%，1.99 ms） |
| 20 | 0.087%（91.3%，2.04 ms） | 0.008%（98.0%，1.23 ms） | 0.195%（79.3%，2.56 ms） | 1.143%（65.3%，2.18 ms） |
| 30 | 0.382%（73.3%，5.15 ms） | **0%（100%，2.46 ms）** | 1.109%（43.3%，2.52 ms） | 2.394%（43.3%，2.73 ms） |

状压 DP 的耗时随 n 指数增长：n=10 约 0.13 ms（内存 1.6 MB）→ n=15 约 6.8 ms（3.9 MB）→ n=20 约 340 ms（168 MB），**n≈23 即为实用上限**，这正是启发式算法存在的理由。

结论要点：

1. n=10 时四种算法全部收敛到最优，差别只在耗时；
2. n≥15 后排序稳定为 **Tabu > ACO > SA > GA**，禁忌搜索在精度、耗时、稳定性三方面同时占优；
3. 蚁群算法用最少的解评价次数（2 250 条完整回路）取得次优精度，代价是每轮 O(n²) 的构造开销；
4. 纯遗传算法效率最低（平均误差 1.45%）且不稳定——它能"找到"最优解但不可靠，需与 2-opt 局部搜索结合才实用。

详见 [`docs/实验报告.md`](docs/实验报告.md) 第五、六、七章。

## 6. 说明

- `results/` 中保存的是报告所引用的那一次完整运行的快照；重跑会覆盖，且**路径长度、误差、命中率完全一致**，只有耗时不同。
- 本实验为单机单线程、`-O2` 的结果，耗时反映的是本实现的效率，不完全等价于算法的固有代价（报告中 8.1 节对此有专门讨论）。
- n=30 超出 DP 可行范围，其参照值由"10 倍预算、四算法多次运行取最好"得到，是可行解上界，故 n=30 的误差偏乐观。
